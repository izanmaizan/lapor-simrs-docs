# SIAP LAPOR (versi awal)

Sistem pelaporan dan pengaduan internal pada lingkungan sistem informasi rumah sakit, ditulis dengan PHP.

## Kegunaan

- Menerima laporan kendala dari unit internal.
- Mencatat tindak lanjut laporan.
- Menyediakan riwayat laporan.

## Tech stack

| Lapis | Teknologi |
|---|---|
| Bahasa | PHP |
| Data | MySQL |
| Infrastruktur | Docker Compose |

## Alur singkat

1. Pengguna mengirim laporan.
2. Petugas mencatat tindak lanjut.
3. Status dan riwayat tersimpan.
